Documento de Arquitectura - Fachada
1. Resumen Ejecutivo
Fachada es una plataforma web que permite a inquilinos y propietarios buscar, consultar y valorar inmobiliarias en España. El objetivo es proporcionar transparencia sobre la gestión de las agencias inmobiliarias, mostrando reseñas verificadas de usuarios reales y datos de contacto actualizados.
Propuesta de valor única: Ninguna plataforma actual (Idealista, Fotocasa, Google Reviews) ofrece reseñas específicas de inquilinos y propietarios sobre la experiencia de gestión inmobiliaria. Fachada cubre ese hueco.
Modelo de negocio: Perfiles verificados para inmobiliarias (?15-30/mes), publicidad contextual (mudanzas, seguros, suministros) y leads cualificados.

5. Flujos Críticos
5.1. Registro y verificación de usuario
Usuario introduce teléfono (+34)
Sistema envía SMS con código de 6 dígitos
Usuario introduce código
Sistema marca telefono_verificado = true
Usuario puede escribir reseñas
5.2. Escribir una reseña
Usuario busca agencia por nombre o ciudad
Usuario hace clic en "Escribir reseña"
Sistema verifica que telefono_verificado = true
Usuario elige rol (inquilino/propietario), puntuación (1-5), título y cuerpo
Sistema guarda reseña con moderado = false
(Opcional) Moderación manual o automática si hay palabras clave sensibles
Reseña se publica
5.3. Reclamar perfil de agencia
Representante de agencia busca su agencia
Hace clic en "Reclamar este perfil"
Sistema pide: nombre, email, teléfono, documentación (CIF, escritura)
Sistema crea claim con estado = pendiente
Admin revisa documentación (manual, al inicio)
Si aprobado: agencia.reclamado = true, agencia.verificado = true
Usuario recibe acceso al panel de agencia
5.4. Responder a una reseña (agencia verificada)
Agencia accede a su panel
Ve listado de reseñas con estado "sin respuesta"
Escribe respuesta (max 500 chars)
Sistema guarda respuesta vinculada a la reseña
Respuesta se muestra públicamente bajo la reseña
6. Seguridad y Compliance
6.1. Protección de datos
GDPR: todos los datos personales encriptados en reposo y tránsito
Derecho al olvido: endpoint para que usuarios soliciten borrado de sus reseñas
Política de privacidad: visible y clara, redactada con asesoría legal
6.2. Moderación de contenido
Sistema de flagging (usuarios pueden reportar reseñas ofensivas/falsas)
Threshold automático: si una agencia recibe &gt;10 reseñas en 48h, se marcan para revisión manual
Proceso de reclamación: formulario visible para agencias que quieran reportar reseñas falsas
6.3. Prevención de abuso
Rate limiting: máximo 1 reseña por usuario cada 7 días hacia la misma agencia
Detección de patrones: alertas si un mismo teléfono escribe muchas reseñas en poco tiempo
Bloqueo de IPs: si se detectan múltiples registros desde la misma IP
6.4. LSSI (Ley de Servicios de la Sociedad de la Información)
Términos y condiciones: redactados por abogado, con cláusula de limitación de responsabilidad
Notice &amp; takedown: proceso documentado para retirar contenido tras reclamación
Contacto legal visible: email y dirección física del responsable
